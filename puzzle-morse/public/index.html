Signal Interception

A continuous radio transmission is flowing down the vertical chamber. Intercept and decode the transmission to find the secret passphrase.

Field Transmission Intel:

  • Sine Wave (On): Active Morse pulse.
  • Flat Line (Off): Gap between pulses or letters.
  • Wavelength: 1 unit = 18px.
  • Pulse Timing: Dot = 1 unit, Dash = 3 units.
  • Gaps: Intra-letter = 1u, Inter-letter = 3u, Words = 7u.
  • Start Signal: When the orb reaches the end, it jumps back to the top and briefly flashes. That jump is the ONLY start signal.
